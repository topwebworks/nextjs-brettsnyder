# Monarch catalog prototype

The existing article and `public/demo/monarch-catalog/` are the source. Brett implemented supplied visual designs as an HTML/CSS prototype for the Angular team, using Material Components for the Web. The companion WordPress microsite was also implemented from supplied designs. Do not credit the supplied identity or illustrations as Brett's original design.

The case study documents declared palette variables, Caladea/Open Sans type roles, Material theme aliases, reusable subject/course/resource patterns, responsive layouts, a detail route and the error view. Six inline boards, a six-page PDF, a source-value snapshot and an actual UI recording support it. The original hero remains.

The archive uses sample content, totals and resource actions. Search/filtering have no catalog API. The microsite and catalog are retired. No current commerce, Angular implementation or conversion outcomes are claimed.
